# Changelog

All notable changes are documented here. The format follows [Keep a Changelog](https://keepachangelog.com),
and the project uses [Semantic Versioning](https://semver.org).

## [1.0.0]

### Added
- Responsive landing page: hero, features, device showcase, customization, testimonials, call to action,
  pricing and contact sections.
- Looping animations, scroll reveal, circular preloader, slim scrollbar and navbar reading-progress bar.
- REST API: health, plans, testimonials, contact, newsletter and protected admin endpoints.
- Validation, honeypot, rate limiting, same-origin check and security headers.
- Custom 404 page, error pages, `robots.txt`, `sitemap.xml`, web manifest and JSON-LD structured data.
- 28 automated tests and a GitHub Actions workflow.
- Documentation: API reference, deployment, MongoDB, SEO and GitHub setup guides.
